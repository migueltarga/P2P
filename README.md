# Série sobre P2P

Uma série em português sobre redes peer-to-peer, escrita por Miguel Targa a partir de estudos, experimentos e curiosidade pessoal.

P2P não é minha área profissional. Compartilho o que aprendo no meu tempo, sem calendário ou obrigação de publicar.

## Diretório

```text
.
├── code/            # Código executável que acompanha os artigos
├── posts/
│   └── pt-BR/       # Artigos em português do Brasil
├── LICENSE
└── README.md
```

Os artigos publicados ficam em [`posts/pt-BR/`](posts/pt-BR/) e seguem o formato `YYYY-MM-DD-titulo-do-artigo.md`.

Os experimentos executáveis ficam em [`code/`](code/) e usam a data e o slug do artigo correspondente.
